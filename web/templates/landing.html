Frequently Asked Questions

What is WireGuard and why is it better? ▼

WireGuard is a modern VPN protocol built into the Linux kernel. It's 4x faster than OpenVPN, uses state-of-the-art cryptography (ChaCha20, Curve25519), and has only 4,000 lines of code (vs OpenVPN's 100,000+) — making it far easier to audit for security.

Do you really store zero logs? ▼

Yes. The server runs on YOUR infrastructure. We don't operate any servers — you do. The code is open source and auditable. There's no centralized logging mechanism. WireGuard itself doesn't log connections by default.

Can my ISP detect I'm using a VPN? ▼

No. Oneline uses traffic obfuscation (wstunnel) that wraps WireGuard traffic inside WebSocket connections. To your ISP, it looks identical to regular HTTPS browsing. This bypasses even deep packet inspection (DPI).

Which platforms are supported? ▼

All major platforms: macOS (native client), Windows, Android, and iOS. Desktop users download a config file, mobile users scan a QR code. Connected in under 60 seconds on any platform.

What do I need to get started? ▼

A VPS (virtual server) for $3-5/month from Hetzner, DigitalOcean, or Vultr. Run our one-command setup script, and the VPN server installs itself. The web panel and client work out of the box.

Can I sell this as my own VPN service? ▼

Absolutely. Oneline comes with an MIT license — you can rebrand it, sell subscriptions, run it as a SaaS business. The admin panel already supports user management, plans, and revenue tracking.
